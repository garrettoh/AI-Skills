# Agent installation workflow

Give your agent this instruction:

> Install the incident response skills from this repository. Read incident-response/README.md and incident-response/AGENT_INSTALL.md. Default to all skills unless I specify individual names. Show me the selected skills, required helpers, destination and existing components that will be updated, then wait for my explicit approval before copying files. After approval, install exactly that selection and verify the installed copy. Report the installed skills, destination and verification results.

1. Resolve the repository, platform and destination. Respect the user's skill selection; default to the complete collection. Use `scripts/install.ps1 -List` or `scripts/install.py --list` when choices are needed.
2. Prepare a concrete plan with `incident-response/scripts/install.ps1 -Preview` on Windows or `python incident-response/scripts/install.py --preview` elsewhere. Include `-Skills` / `--skills` and the destination when specified. A preview must not create the installation destination or copy any components.
3. Show the preview output to the user and request explicit approval. This guide requires confirmation before actual installation, even when the initial request says "install". Approval must cover the exact selection, dependencies, destination and disclosed file updates. Never infer approval from elapsed time, missing input or a default selection. If a previous user message already explicitly approves that exact displayed plan, do not ask again.
4. After approval, use the same command with `-Yes` / `--yes` instead of preview, or let the user confirm interactively. These flags acknowledge approval already received; they do not replace it. If the plan changes, preview the changed plan and obtain approval for it before copying.
5. Wait for the installed-copy verifier. Partial installs verify only selected skills and required helpers. Verification uses isolated synthetic evidence and does not inspect case evidence or install Python packages. Report any failure and destination; do not claim success. To recheck, use `incident-response/scripts/verify_install.py --skills-root DESTINATION --skills APPROVED_NAMES` (omit the selection only for a complete installation).

All current skills can be installed individually. Shared helpers are automatically included; other skill folders are not automatically selected. Existing unselected skills are retained. Hindsight resides at incident-response/hindsight-orchestrator, independently of kape_analysis. The main investigation skill and shared workflow also have separate incident-response folders.
